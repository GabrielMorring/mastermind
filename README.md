# mastermind

## Overview

In this game you have two players (who I am calling player and dealer). The dealer comes up with a secret code that is a sequence of four colors, the color options are red, green, blue, yellow, orange, or purple. The player then gets twelve guesses to find the code. For each guess the dealer tells the player how many partially correct colors they got (correct color in wrong position) and how many absolutely correct colors they got (correct color in correct position). If the player guesses correctly within twelve guesses they win. If not, the dealer wins.
